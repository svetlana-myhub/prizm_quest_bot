# Prizm Quest — прогресс проекта

Дата обновления: 2026-08-26

## Суть проекта

Обучающий Telegram-бот о криптовалюте Prizm для новичков и тех, кто уже знаком.
Цель: просто и с жизненными примерами объяснить основы, научить безопасности
(сид-фраза!), провести квест и выдать награду по правилам.

- Бот (username): @PrizmQuestBot
- Репозиторий: https://github.com/svetlana-myhub/prizm_quest_bot (приватный)

## Окружение

- GitHub: svetlana-myhub
- PythonAnywhere (деплой позже): логин svetanaconda
- Рабочий компьютер: macOS, папка ~/projects/prizm_quest bot
- Домашний компьютер: Windows, папка PS E:\БОТЫ\projects\prizm_quest_bot
- Токен бота: хранится ТОЛЬКО в файле .env на каждом компьютере, в Git не попадает
- Мой Telegram ID: в .env в переменной ADMIN_TG_IDS

## Принципы (не нарушать)

1. Бот НИКОГДА не спрашивает сид-фразу, приватный ключ, пароли.
2. Если пользователь прислал похожее на сид-фразу — предупредить, не сохранять.
3. .env и база данных никогда не коммитятся в Git.
4. Награда — одна на пользователя (UNIQUE(tg_id, code) в таблице rewards).
5. Реальные выплаты — сначала только вручную, с проверкой админом.
6. Контент — без обещаний дохода, обучающий тон.

## Как запустить локально

macOS:

    cd ~/projects/prizm_quest_bot
    source .venv/bin/activate
    python bot.py

Windows:

    cd путь\к\prizm_quest_bot
    .venv\Scripts\activate
    python bot.py

Остановить бота: Ctrl + C

## Правила синхронизации двух компьютеров

1. Закончила работу на компьютере — сделай commit и push.
2. Села за второй компьютер — сначала git pull.
3. Никогда не запускать бота с одним токеном на двух машинах одновременно.
4. .env и botdata/*.db не синхронизируются — на каждой машине свои.
