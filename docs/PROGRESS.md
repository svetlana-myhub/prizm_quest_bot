# Prizm Quest — прогресс проекта

Дата обновления: 2026-09-08

## Суть проекта

Обучающий Telegram-бот о криптовалюте Prizm для новичков и тех, кто уже знаком.
Цель: просто и с жизненными примерами объяснить основы, научить безопасности
(парольная фраза!), провести квест и выдать награду по правилам.

- Бот (username): @PrizmQuestBot
- Репозиторий: https://github.com/svetlana-myhub/prizm_quest_bot (приватный)

## Окружение

- GitHub: svetlana-myhub
- PythonAnywhere (деплой): логин svetanaconda
- Рабочий компьютер: macOS, папка ~/projects/prizm_quest_bot
- Домашний компьютер: Windows, папка E:\БОТЫ\projects\prizm_quest_bot
- Токен бота: хранится ТОЛЬКО в файле .env на каждом компьютере, в Git не попадает
- Мой Telegram ID: в .env в переменной ADMIN_TG_IDS

## Принципы (не нарушать)

1. Бот НИКОГДА не спрашивает парольную фразу (сид-фразу), приватный ключ, пароли.
2. Если пользователь прислал похожее на парольную фразу — предупредить, не сохранять.
3. .env и база данных (botdata/*.db) никогда не коммитятся в Git.
4. Награда — одна на пользователя (UNIQUE(tg_id, code) в таблице rewards).
5. Реальные выплаты — сначала только вручную, с проверкой админом.
6. Контент — без обещаний дохода, строго обучающий тон.
7. Бейджи и статусы разделены: бейджи — это история достижений, статус — текущий наивысший уровень.
