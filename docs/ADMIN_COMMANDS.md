# Админские команды Prizm Quest Bot

## Управление пользователями
- `/admin_reset <tg_id>` — полный сброс прогресса пользователя
- `/user <tg_id>` — карточка пользователя
- `/paid <tg_id>` — отметить выплату награды

## Статистика и рассылки
- `/stats` — общая статистика бота
- `/pending` — заявки на выплату
- `/broadcast <фильтр> <текст>` — рассылка (all, active, quest_done, quest_not_done, inactive)
- `/export` — выгрузка данных в CSV

## Важно
- Все команды доступны только пользователям из `ADMIN_TG_IDS` в `.env`
- Обычные пользователи эти команды не видят в списке `/`
