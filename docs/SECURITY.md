# Безопасность проекта

## Главные правила

1. Бот никогда не запрашивает сид-фразу.
2. Бот никогда не запрашивает приватный ключ.
3. Бот никогда не запрашивает пароль от кошелька.
4. Бот никогда не запрашивает пароль от Telegram.
5. Секретные данные не пишутся в логи.
6. Награды выдаются по одному разу на пользователя.
7. Реальные выплаты сначала проходят ручную проверку.

## Если пользователь присылает сид-фразу

Нужно:

1. Не сохранять текст.
2. Предупредить пользователя.
3. По возможности удалить сообщение.
4. Напомнить правила безопасности.

## Хранение данных

Минимально хранить:

- Telegram ID;
- username;
- имя;
- прогресс;
- кристаллы;
- бейджи;
- заявки на награды.

Не хранить:

- сид-фразы;
- приватные ключи;
- пароли;
- лишние личные сообщения.
