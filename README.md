# 🟣 Prizm Quest Bot

Репозиторий содержит два Telegram-бота для экосистемы **PRIZM (PZM)** в сети TON.

---

## 🤖 1. Alert Bot — курсы, графики и оповещения о сделках

Telegram-бот для отслеживания курсов, ликвидности и сделок токена PZM на бирже **DeDust**.

### Возможности
- 📊 **Живые графики** изменения курса PZM к USDT, GRAM и RUB (7 дней / 1 месяц / 1 год).
- 💰 **Актуальная ликвидность** — данные берутся напрямую из смарт-контракта пула через TON Center API (`get_reserves`), в обход устаревшего публичного API DeDust.
- 🔢 **Калькулятор** стоимости любого количества PZM по текущему курсу.
- 🔔 **Оповещения о сделках** — автоматическая публикация покупок/продаж в настроенные чаты и каналы.
- 🧹 **Чистота в группах** — умное самоудаление команд, подсказок и ошибок.

### Команды
| Команда | Описание |
|---------|----------|
| `/rate` | Текущий курс PZM с краткой сводкой |
| `/chart` | График курса (расчёт по умолчанию для 1000 PZM) |
| `/calc` | Интерактивный калькулятор стоимости |
| `/cancel` | Отмена текущего действия |
| `/activity` | Журнал активности (для админов) |
| `/health` | Проверка состояния бота |

### Технологический стек
- Python 3.10+, `pyTelegramBotAPI` (telebot)
- SQLite (`db.py`)
- TON Center API (живые резервы смарт-контракта)
- DeDust API (метаданные активов)
- Хостинг: PythonAnywhere

### Структура файлов alert-бота
- `alert_bot.py` — обработчики команд и inline-кнопок
- `chart.py` — генерация графиков (matplotlib) и форматирование подписей
- `market.py` — работа с внешними API (курсы, ликвидность)
- `db.py` — функции для работы с SQLite

## 🎓 2. Quest Bot — обучающий бот о Prizm

Обучающий Telegram-бот, помогающий новичкам разобраться в экосистеме Prizm.

### Цель проекта
Помочь новичкам понять:
- что такое Prizm;
- зачем нужен криптокошелёк;
- почему важно беречь сид-фразу;
- как безопасно делать первые шаги;
- как не попадаться на мошеннические схемы.

### Основной сценарий
1. Пользователь запускает бота.
2. Выбирает уровень: новичок или уже знаком.
3. Проходит 10 фактов о Prizm.
4. Отвечает на мини-вопросы.
5. Проходит квест.
6. Получает бейджи и кристаллы.
7. В конце может получить награду по условиям проекта.

### Безопасность
Бот **никогда** не запрашивает:
- сид-фразу;
- приватный ключ;
- пароль от кошелька;
- пароль от Telegram.

### Статус
Создан каркас проекта и черновой контент.
